# MEDORA

## An Intelligent Real-Time Emergency Resource Allocation and Coordination System for Better Critical Resource Availability

## Problem
During emergencies, finding suitable hospital resources quickly can be difficult. 
MEDORA aims to help emergency teams identify and reserve suitable hospital resources 
using priority-based allocation and safe database transactions.

## Objectives
- Real-time emergency resource coordination
- Priority-based allocation of critical resources
- Safe and conflict-free resource reservation
- Integration of OS scheduling and DBMS concurrency control
- Future availability prediction using ML

including hospitals, ambulances, patients, emergency requests, resources, 
reservations, and reservation events.
